First 60 seconds

The Netflix performance team’s ten commands, in order, with what to look for. Run each at a one-second interval; ignore the first line of vmstat, mpstat, and iostat (averages since boot). Lessons 3 to 7 explain each.

CommandUSE cellLook for
uptimeCPU demand1 versus 15 minute load; compare with nproc
dmesg -T | tailErrors, allOOM kills, TCP drops, I/O errors
vmstat 1CPU S, memory Sr above CPUs, b high, si/so, wa, st
mpstat -P ALL 1CPU UOne hot CPU, steal, iowait
pidstat 1CPU U by processTop consumers, rolling
iostat -xz 1Disk U, Sawait, queue size, throughput; %util is misleading on parallel devices
free -mMemory Uavailable, not free
sar -n DEV 1Network URx and Tx versus link speed
sar -n TCP,ETCP 1Network S, ERetransmits, connection rate
topSanity checkAnything missed

Direct saturation signals

$ cat /proc/pressure/cpu /proc/pressure/memory /proc/pressure/io
$ grep -E 'MemAvailable|SwapFree' /proc/meminfo

Install before the crisis

$ sudo apt install procps util-linux sysstat iproute2 numactl tcpdump \
    linux-tools-common linux-tools-$(uname -r) bpfcc-tools bcc bpftrace \
    trace-cmd nicstat ethtool tiptop cpuid msr-tools
