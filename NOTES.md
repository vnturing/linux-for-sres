# Notes

- Learner preference: learn sequentially, building ideas on top of each other. Each lesson opens with a bridge from the previous one.
- Always draw diagrams with Mermaid, never ASCII art.
- Target learner: software engineer with desktop-level Linux experience moving toward platform/SRE work.
- Drills assume a disposable Debian or Ubuntu VM with sudo and systemd. Package names follow Ubuntu.
- Quiz rule: every option in a question has the same number of words; the correct answer's position varies. The build script enforces equal word counts.
- Glossary terms in GLOSSARY.md are the course's canonical vocabulary; lessons must use them as written.
- Next lessons to write when extending: cgroups and container OOM (needs a source, see RESOURCES.md Gaps), firewall and conntrack triage, storage layers, cron and timers, TLS and certificate expiry.
